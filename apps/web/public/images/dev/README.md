# Development assets — replace before launch

Every image in this folder was cropped and upscaled from design mockups supplied by the
client (the original "Fresh Basket" concept and the four "Ram Avatar Fresh Basket" page
mockups). They are **development placeholders only** — their licence/origin has not been
verified, and the upscaled crops are lower resolution than real product photography.

Before going live, upload licensed photos (your own shoot, or a stock licence that allows
commercial e-commerce use) in Admin → Products and Admin → Categories, or replace these
files keeping the same names.

Extra crops you can attach to new products in Admin (paste the path as the photo URL):

cauliflower.jpg, cabbage.jpg, garlic.jpg.
