# Storefront photos — sources and licences

These banner/hero photos are **CC0 / public domain** (no attribution required, commercial use allowed),
found through Openverse (openverse.org) and hosted by rawpixel.com. `scripts/site-images.mjs` downloads
them into this folder (1024 px wide WebP). Before launch, open each source page once and confirm the
"CC0 / Public Domain" label is still shown there.

| File | Used for | Source page | Licence |
|---|---|---|---|
| hero-veg-basket.webp | Home hero, slide 1 | https://www.rawpixel.com/image/5916958/image-public-domain-plant-greens | CC0 |
| hero-shopping-basket.webp | Home hero, slide 2 | https://www.rawpixel.com/image/5915695/image-public-domain-plant-greens | CC0 |
| banner-market.webp | Shop, cart and default page banners | https://www.rawpixel.com/image/5921048/photo-image-public-domain-plant-green | CC0 |
| banner-roots.webp | Info pages, WhatsApp order page | https://www.rawpixel.com/image/6073066/photo-image-public-domain-plant-food | CC0 |
| tile-all.webp | "All products" tile on /categories | https://www.rawpixel.com/image/5965619/fresh-vegetables-the-basket | CC0 (per Openverse) |
| tile-seasonal.webp | "In season" tiles | https://www.rawpixel.com/image/5915753/image-background-white-public-domain | CC0 |

If a download fails, the script copies the old development image from `images/dev/` under the same name, so
nothing breaks. Product and category photos are separate: upload them in Admin → Products / Categories.
